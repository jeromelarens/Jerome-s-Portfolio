## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/jeromelarens/Jerome-s-Portfolio.git
```

### Navigate to Project Directory

```bash
cd Jerome-s-Portfolio
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
